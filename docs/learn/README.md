# Learn: from zero to understanding this project

A learning path for people who have **never programmed before**. It is made of **39 lessons of about 10 minutes each** (roughly 6½ hours in total), in 9 modules. Every lesson links to a free, high-quality resource and ends with a hands-on exercise in *this* project, so you learn the theory and immediately see it in real code.

## Start here

1. Read **[This project, explained from scratch](00-the-project-explained.md)** (15 minutes). It gives you the big picture with no code.
2. Keep the **[Glossary](glossary.md)** open in another tab.
3. Work through the modules in order. One or two lessons a day is plenty.

## How each lesson is laid out

> **Goal:** what you'll understand by the end
> **Learn (≈5–7 min):** a free article to read, with the exact sections named
> **Try (≈3–5 min):** something to do: in the browser, the terminal or this project's code
> **In this project:** where the idea appears in Atlas of Art
> **Check yourself:** one question to confirm you've got it

## Before you start

- **Computer:** Windows, macOS or Linux. Node.js (version 20 or newer) and Git are needed; Lesson 1.3 checks that they're installed.
- **Making mistakes is safe.** Every change is tracked by Git. If something breaks, this command undoes all changes you haven't committed:

```bash
git restore .
```

- **Never** paste secret keys into code, chats or screenshots (see Lesson 9.3).
