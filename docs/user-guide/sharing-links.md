# Sharing links

Every combination of filters is saved in the page address, so you can:
- **Share a search.** Copy the address from Explore and send it. The other person sees the same regions, era, styles, keyword, sort and view.
- **Bookmark** a search you like.
- **Undo** with the browser's back button.

Example: Ukiyo-e from 18th-century East Asia, shown as a timeline:

```
/explore?regions=east-asia&from=1700&to=1799&styles=ukiyo-e&view=timeline
```

To share a single artwork, use **Copy link** on its page.

Results come live from the museums, so a shared search can show slightly different works over time as museums update their collections.
